# lab-onboarding-Maximov
## Практическая работа 9. Аудит ПО

### Категории базового ПО
Для оценки пригодности компьютера к офисной работе выбраны следующие категории:
* **Офисный пакет** (Office, LibreOffice, МойОфис) — для работы с документами.
* **Браузер** (Chrome, Firefox, Яндекс) — для доступа к веб-ресурсам.
* **PDF-ридер** (Acrobat, Foxit, SumatraPDF) — для чтения документации.
* **Архиватор** (7-Zip, WinRAR) — для работы с архивами и вложениями из почты.
* **Антивирус** (Defender, Kaspersky, ESET) — для базовой безопасности.

### Признаки излишнего ПО
Поиск ведется по ключевым словам:
* **Игры:** Steam, Epic Games, GOG, Origin, game, gaming.
* **Торренты:** torrent, uTorrent, BitTorrent, qBittorrent.
* **Мессенджеры:** Discord, Telegram, WhatsApp, Skype.
* **Развлечения:** Wallpaper Engine, OBS, Soundpad.

### Как проверялась работоспособность логики
Логика проверялась в двух сценариях:
1. **Поиск недостающего ПО:** скрипт успешно выявил отсутствие архиватора (или другого ПО) и выдал текстовую рекомендацию.
2. **Поиск излишнего ПО:** на тестовой машине были найдены uTorrentClient и Steam, скрипт корректно вывел их в раздел «Проверка излишнего ПО» с пометкой о необходимости проверки, а не удаления.

### Ограничения решения
Скрипт не определяет дату последнего запуска программ, поэтому формулировка «не относится к базовым задачам» является рекомендацией к ручной проверке администратором, а не строгим приказом к удалению. В некоторых организациях Skype или Telegram могут быть легитимными рабочими инструментами.
